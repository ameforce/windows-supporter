# 사용 한도 초기화 알림에 프로필 이름 표시 hotfix

## 의도와 변경 분류

- 의도한 계약: 사용 한도가 초기화되면 그 프로필의 효과음과 알림 툴팁을 한 번 표시한다(v0.33.0, v0.33.16). 알림은 여러 프로필 가운데 어느 프로필이 초기화됐는지 알 수 있어야 한다.
- 현재 동작: Codex 알림 첫 줄은 "Codex 현재 사용량", Claude 알림 첫 줄은 "Claude 사용 한도 초기화"로 고정되어 있다. 프로필이 여러 개면 비슷한 알림이 연달아 떠서 어느 계정이 초기화됐는지 알 수 없다. v0.33.16 배포 직후 Codex 프로필 여러 개가 한꺼번에 알림을 낸 상황이 그 예다.
- 차이: 알림이 초기화된 프로필을 가리키지 못한다.
- 판정: 새 기능 없이 기존 알림 표시를 완성하는 개선이므로 `hotfix/v0.33.17`로 분류한다.

## 원인

알림을 띄우는 것은 프로필별 모니터(`CodexUsageMonitor`, `ClaudeUsageMonitor`)다. 화면의 프로필 카드 이름은 다중 프로필 관리자(`CodexUsageMultiMonitor.__display_account_label`)가 이름 표시 방식에 따라 정한다. 자동 방식이면 확인된 계정 이름, 사용자 지정 이름, 기본 이름(`Codex 7` 등) 순서로 고르고, 사용자 지정 방식이면 사용자 지정 이름을 쓴다. 모니터는 이 이름을 전달받지 않아 알림에 넣을 수 없었다.

## 수정

- 관리자가 프로필 모니터를 만들 때(`__invoke_monitor_factory`) 이름을 돌려주는 함수를 `set_alert_label_provider`로 연결한다. 모든 모니터 생성 경로가 이 함수를 지나므로 설정 변경이나 복구로 모니터를 다시 만들 때도 연결된다.
- 이 함수는 알림을 표시하는 순간 카드와 같은 규칙으로 이름을 구한다. 이름을 바꾸거나 계정 이름이 새로 확인되면 다음 알림부터 바로 반영된다. 프로필이 삭제됐거나 이름을 구하지 못하면 빈 값을 돌려준다.
- Codex 알림 첫 줄은 "Codex 현재 사용량 - {프로필 이름}", Claude 알림 첫 줄은 "Claude 사용 한도 초기화 - {프로필 이름}"이 된다. 이름이 없으면 예전 문구를 그대로 쓴다. 관리자 없이 단독으로 쓰는 모니터도 예전과 같다.

## 검증 범위

- 공용 알림 모듈: 이름이 있으면 첫 줄에 붙고, 빈 값이나 오류면 예전 문구를 쓴다.
- Claude 모니터: 관리자가 넘긴 함수로 첫 줄이 바뀌고, 연결을 풀면 예전 문구로 돌아간다.
- Codex 모니터: 초기화 알림 첫 줄에 이름이 붙고, 빈 값, 오류, 연결 없음에서는 예전 문구를 쓴다.
- 관리자: 모든 프로필 모니터가 카드와 같은 이름을 받고, 사용자 지정 이름으로 바꾸면 새 이름을 받으며, 없는 프로필은 빈 값을 받는다.
- 새 시험은 수정 전 코드에서 실패한다. Codex, Claude, Cursor 모니터와 다중 프로필 관리자, 초기화 알림 관련 시험 389건을 함께 실행했다.
