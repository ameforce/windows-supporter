# Hotfix v0.31.1 — Flex 실제 퇴근 표시

## 분류

- 의도한 계약: 실 출근과 실 퇴근 기록이 모두 있으면 패널에 Flex 계획 퇴근이나 계산된 예상 퇴근 대신 실제 퇴근 시각을 표시한다.
- 현재 동작: Flex의 `actual_quit`이 있어도 오늘 패널은 항상 `예상 퇴근` 라벨과 계산값을 표시했다.
- 차이: 완료된 실 출퇴근 기록과 진행 중 예상 퇴근의 표시가 구분되지 않았다.
- 판정: 새 capability나 정책이 아니라 기존 Flex 실 퇴근 데이터의 표시 누락을 복구하는 변경이므로 `hotfix/v0.31.1`로 분류한다.

## 변경 계약

- `actual_start`와 `actual_quit`이 모두 확인되면 `출근 HH:MM · 실제 퇴근 HH:MM`을 표시한다.
- 실 퇴근 기록이 없으면 기존처럼 `출근 HH:MM · 예상 퇴근 HH:MM`을 표시한다.
- 초과근무 경계와 예상 퇴근 계산은 변경하지 않는다.

## 검증 범위

- 실 출근만 있는 Flex fixture에서 기존 `예상 퇴근` 표시를 유지한다.
- 실 출퇴근이 완료된 Flex fixture에서 실제 퇴근 시각을 표시하고 `예상 퇴근`을 표시하지 않는다.
