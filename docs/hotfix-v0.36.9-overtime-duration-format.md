# Hotfix v0.36.9 — 초과근무 시간 표기 개선

## 의도한 계약 → 현재 동작 → 차이 → 판정

- 의도한 계약: 초과근무 경과 시간과 배정 시간은 길어져도 바로 읽을 수 있도록 시간·분 단위로 표시한다.
- 현재 동작: 툴팁, 근무시간 요약, 진행/일시정지 카드와 연장 배정 안내가 모두 분 단위 정수로 표시된다. 예를 들어 309분이 `309분`으로 나타난다.
- 차이: 한 시간이 넘는 초과근무를 시각적으로 빠르게 파악하기 어렵다.
- 판정: 사용자가 요청한 표기 개선이며 새 기능이나 정책을 추가하지 않으므로 hotfix로 분류한다.

## 변경 계약

- 0~59분은 분으로 유지한다. 60분부터 `1시간`, `1시간 5분`처럼 표시한다.
- 이 표기는 자동 툴팁, 근무시간 요약, 활성/일시정지 상태와 Flex 배정 안내에 동일하게 적용한다.
- 계산, 일시정지, 예정 퇴근 및 저장 동작은 변경하지 않는다.

## 검증 범위

- 직접 호출 경로: 초과근무 툴팁/요약 텍스트와 근무시간 패널의 안내·진행 상태 텍스트.
- 단위 검증: `test_wrike_realtime_progress.py`, `test_wrike_worktime_panel.py`에서 59/60/65/309분 경계와 활성/일시정지 문구를 확인한다.
- UI-visible 검증: 변경된 초과근무 툴팁과 근무시간 카드만 확인한다.
- build 검증: UI 표시 변경이므로 task candidate build와 clean tagged candidate build를 실행한다. candidate build는 설치된 runtime을 변경하지 않는다.
