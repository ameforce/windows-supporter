# v0.37.1 작업표시줄 API 크레딧 칸

## 판정

- 의도한 계약: v0.37.0 요청은 OpenAI Platform API 크레딧 잔액을 Codex 사용량과 같이 띄우는 것이었다. Codex 사용량의 주 표시 위치는 작업표시줄 compact 행이다.
- 현재 동작: v0.37.0은 잔액을 작업표시줄 호버 툴팁에만 보여 준다(`docs/release-v0.37.0-codex-api-credit.md`의 "새 슬롯을 만들지 않는다" 결정).
- 차이: 작업표시줄에서 잔액을 보려면 지표 위에 마우스를 올려야 한다.
- 판정: 새 기능이 아니라 요청한 표시를 완성하는 일이므로 hotfix다. 위 v0.37.0 결정은 이 문서로 바뀐다.

## 동작

- 잔액을 마지막에 정상으로 읽었으면 Codex 행의 금액 칸에 `API $12.34`로 보인다. 금액 칸은 ChatGPT 크레딧 `CR`과 같은 칸 구조(막대 없음, 좁으면 `$1.2K`, `$1K`처럼 짧게)를 쓴다.
- 한 행에는 금액 칸이 하나다. `CR`이 이미 있거나 사용량 지표 3개(5시간, 주간, 월간)가 모두 보고되면 API 칸을 만들지 않고, 잔액은 다른 칸의 호버 툴팁에 남는다.
- 로그인이 필요하거나 읽지 못한 경우에는 칸을 만들지 않는다. 이전 값은 툴팁에 `(이전 값, 로그인 필요)`처럼 표시한다.
- 칸 이름표가 `CR`보다 넓으므로, 금액 시작 위치는 금액이 달러 표기인지로 이름표를 정해 계산한다. 폭 계산과 그리기가 같은 위치를 쓴다.

## 검증

- 자동 테스트: 칸 생성 조건(정상 읽기만, `CR` 우선, 3칸 규칙, 다른 제공자 제외), 달러 금액의 짧은 표기, 이름표 뒤 금액 위치, 좁은 칸의 짧은 표기, 선호 폭이 금액 전체를 담는지, 기존 `CR` 위치 불변.
