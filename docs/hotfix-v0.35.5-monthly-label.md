# 월간 한도 표기를 1M으로 정리

월간 한도의 짧은 표기는 월 단위라는 의미를 전달해야 한다. 현재 `30D` 표기는 고정 30일처럼 읽히며 `5H`, `7D`보다 길다. 기존 표시의 의미와 가독성을 보완하는 변경이므로 `hotfix/v0.35.5`로 분류한다.

공급자별 지표 생성 경로와 이전 형식 스냅샷을 표시하는 대체 경로의 월간 표기를 모두 `1M`으로 바꾼다. `monthly_limit` 식별자와 기간 계산, 초기화 시각, 사용량, 색상, `월간 한도` 툴팁은 그대로다.

기존 월간 지표 시험과 관련 표시 시험, 단일 사용량 배치 시험을 실행하고 변경된 두 행의 실제 Tk 화면 및 설치된 앱을 확인한다. 단순 표기 변경이므로 별도 독립 검토나 Pro 검토, 전체 테스트 모음과 전체 앱 E2E는 추가하지 않는다.

관련 기존 시험 11개와 실제 Tk 렌더링을 통과했다. `월간 한도` 툴팁과 시간 계산 코드는 변경하지 않았다.
