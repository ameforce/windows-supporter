# Hotfix v0.30.1 — Flex 실제 출근 시각 기반 초과근무 경계

## 분류

- 의도한 계약: 실제 출근 시각을 기준으로 Flex의 순근무시간과 병합 휴게를
  적용해 예상 퇴근과 초과근무 시작 시각을 계산한다.
- 현재 동작: Flex 동기화가 계산한 8시간 순근무시간과 별개로 초과근무 판정이
  Flex의 계획된 정규 퇴근 시각을 우선 사용했다. 계획 출근 08:00, 실제 출근
  08:45인 날에도 17:00에 초과근무 알림이 표시될 수 있었다.
- 차이: 초과근무 경계가 실제 출근 및 근무시간 계산과 분리되어 계획 시각에
  고정돼 있었다.
- 판정: 새 capability나 정책이 아니라 기존 실시간 근무시간 계산 계약의
  누락을 복구하는 변경이므로 `hotfix/v0.30.1`로 분류한다.

## 변경 계약

- Flex의 순근무시간을 사용하고, 실제 출근 시각에서 시작하는 공통 퇴근 계산을
  적용한다. 승인된 Flex 연장은 전체 목표에는 포함하되 초과근무 측정 시작점은
  정규근무분(`target_minutes - overtime_assigned_minutes`)으로 계산한다.
- Flex의 계획/정규 퇴근 시각은 실제 출근이 확인된 경로의 초과근무 경계를
  덮어쓰지 않는다.
- 패널 요약도 실제 출근이 확인된 경우 `Flex 근무 ... · 실제 출근 ... 기준`으로
  표시해 계획 퇴근 시각이 계산 기준처럼 보이지 않게 한다.

## 검증 범위

- Flex 계획 출근 08:00, 실제 출근 08:45, 순근무 8시간, 점심 휴게 1시간
  fixture에서 예상 퇴근이 17:45인지 확인한다.
- 17:05 활동에서는 pending 초과근무가 생성되지 않고, 17:46 활동에서
  17:45 기준 pending 상태가 생성되는지 확인한다.
- 패널 요약이 실제 출근과 예상 퇴근을 표시하고 `Flex 퇴근 17:00`을 계산 기준으로
  노출하지 않는지 확인한다.
