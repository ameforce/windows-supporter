# 작업표시줄 프로필명 표시 폭 복구

## 목적과 변경 분류

작업표시줄 AI 사용량 오버레이에서 현재 프로필명을 실제 이름 그대로 식별할 수 있어야 한다.

- 의도한 계약: `Daeng - enmsoftware`, `Daeng - ameforce`처럼 검증된 프로필명을 표시 영역에서 끝까지 읽을 수 있다.
- 현재 동작: 렌더러가 프로필명을 `label[:8]`로 잘라 표시하고, 레이아웃 폭 계산도 프로필명 폭을 고려하지 않는다.
- 차이: 실제 프로필명을 읽어도 작업표시줄에서는 앞 8자만 보이며, 제한을 단순히 늘리면 긴 이름이 상태 점·메트릭과 겹칠 수 있다.
- 판정: 새 capability 도입이 아닌 기존 프로필 식별 표시의 불완전 구현 복구이므로 `hotfix/v0.21.1` 후속 fix로 분류한다.

## 수정 계약

- 프로필명은 고정 글자 수가 아니라 실제 오버레이 글꼴의 픽셀 폭으로 측정한다.
- 선호 오버레이 폭 계산에 모든 표시 프로필의 최대 이름 폭을 포함해, 여유 슬롯에서는 전체 이름이 들어갈 만큼 오버레이를 확장한다.
- 실제 native Tk 측정기를 사용하고 headless 경로에는 보수적인 fallback을 사용해 DPI와 테스트 환경의 폭 계산을 같은 계약으로 유지한다.
- 정상 폭에서는 프로필명을 자르지 않는다. 슬롯이 메트릭 우선 compact fallback까지 좁아진 경우에만 가용 픽셀에 맞춘 말줄임표를 사용한다.
- 메트릭의 기존 compact 축약·상태 표시 우선순위는 유지한다.
