# 휴게 기록 수정과 활동 알림 저장 복구

완료된 수동 휴게 시간을 수정하고, 활동 알림 저장 실패의 원인과 반복 표시를 함께 해결한다. 선택한 날짜의 타임로그에서는 티켓 제목, 기록 시간, 설명을 구분해 읽을 수 있도록 표시한다.

## 변경 분류

기존 상태 저장 결함과 표시 개선만으로는 핫픽스에 해당한다. 이번 변경에는 완료된 수동 휴게 구간을 수정하는 새 기능이 포함되므로 `release/v0.21.0`으로 분류한다.

## 저장 결함과 복구 범위

휴게 시작 시각은 초 단위로 저장되지만, 종료 시각은 마이크로초까지 포함한 값으로 비교됐다. 같은 초 안에 시작하고 종료하면 비교 단계에서는 양수인 구간이 저장 단계에서 0초 구간으로 바뀔 수 있었다. 예를 들어 `09:00:00.100000`과 `09:00:00.800000`은 모두 `09:00:00`으로 저장됐다.

상태 파일을 다시 읽을 때는 0초 구간을 거부하므로 파일 전체가 쓰기 차단 상태가 됐다. 활동 감지 콜백은 저장 실패 후에도 입력마다 같은 저장과 오류 알림을 반복했다. 이 생성 및 재로딩 경로는 임시 파일로 재현했으며, 실제 상태 파일에서도 같은 형태의 0초 구간을 확인했다. 실제 행을 생성한 개별 입력 이벤트는 확인하지 않았다.

완료 구간을 추가하는 공통 경로에서 초 단위 저장 결과가 양수인지 확인한다. 기존 파일에 남아 있는 정상 형식의 0초 구간은 보존하고, 휴게 합계에서는 제외하며, 수동 휴게 편집 대상으로 제공한다. 음수 구간, 잘못된 시각 형식, 날짜 범위를 벗어난 구간은 계속 거부한다.

활동 알림 저장은 실패 뒤 일정 간격으로 재시도한다. 같은 실패가 이어지는 동안 오류 알림을 반복하지 않으며, 저장 성공 후 실패 상태를 해제한다.

## 휴게 수정 계약

선택 날짜의 완료된 수동 휴게에서 시작과 종료 시각을 수정한다. 종료 시각은 시작보다 뒤여야 하며, 해당 날짜의 끝은 `24:00`으로 표시한다. 캘린더에서 가져온 휴게는 출처를 표시하고 읽기 전용으로 제공한다.

편집 요청은 날짜, 목록 위치, 편집을 시작한 목록의 지문을 함께 전달한다. 저장 직전에 잠금 안에서 목록이 그대로인지 확인하고, 다른 변경이 있으면 덮어쓰지 않고 충돌을 알린다. 파일 교체가 실패하면 메모리 상태도 복구한다. 선택하지 않은 휴게, 다른 날짜의 기록, 출근 및 목표 시간은 편집 대상이 아니다.

`Ctrl+Alt+B` 전역 단축키는 등록하지 않는다. 패널의 휴게 시작·종료 버튼은 유지한다.

## 검증 범위

상태 읽기·쓰기와 편집의 경계값, 활동 저장 실패와 복구, 전역 단축키 등록, 변경된 패널의 표시 및 편집 상태를 직접 검증한다. 실제 상태 파일의 복구 확인은 사본에서 수행하며, 합성 휴게 기록으로 화면 편집과 저장을 확인한다. 관련 없는 화면과 전체 테스트 모음은 실행하지 않는다.
