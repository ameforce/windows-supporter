# Release v0.31.0 — AI 사용량 작업표시줄 배치 및 탭 폭

## 분류 판정

- 의도한 계약(신규): AI 사용량 사용자는 AI 탭에서 작업표시줄 오버레이가 선택된 프로필을 배치할 때 왼쪽 우선 또는 오른쪽 우선 정책을 선택할 수 있다. 선택값은 저장되고 다음 조회/재시작에도 유지된다.
- 의도한 계약(보완): AI 사용량 탭에 진입하면 실제 설정·프로필·상태 콘텐츠와 스크롤바를 수용하는 기본 폭을 계산해 초기 화면에서 항목이 잘리지 않는다.
- 현재 동작: 오버레이 coordinator가 첫 두 프로필을 항상 왼쪽 pane에 배치하고, main shell은 AI view에 content-fit 크기 계약이 없어 고정 900px fallback에 의존한다.
- 차이: 배치 방향을 사용자가 선택할 수 없고, 실제 scroll body의 요청 폭이 기본 창 크기에 반영되지 않아 긴 프로필/상태 항목이 초기 viewport 밖으로 잘릴 수 있다.
- 판정: 좌/우 배치 선택은 새 사용자 capability이므로 `release/v0.31.0`으로 분류한다. 폭 계산 보완은 같은 AI 탭 표시 계약을 완성하는 호환 수정으로 같은 lane에 포함한다.

## 수용 기준

1. AI 탭에 `왼쪽 우선`/`오른쪽 우선` 선택 UI가 표시된다.
2. 선택값이 `ai_usage_settings.json`에 round-trip되고 runtime snapshot에 노출된다.
3. 오버레이는 선택한 방향에 선택 프로필 1·2를 우선 배치하며, 반대 방향에는 3·4를 배치한다. 기존 설정에 값이 없으면 현재 표시 동작인 왼쪽 우선을 유지한다.
4. AI view가 mount된 뒤 scroll body와 scrollbar의 실제 요청 크기가 main shell의 기본 geometry 계산에 반영된다.
5. 변경 경로에 직접 연결된 unit/contract 검증과 native AI 화면 검증을 수행한다.
