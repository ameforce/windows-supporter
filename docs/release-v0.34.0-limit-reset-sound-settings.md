# v0.34.0 사용 한도 초기화 효과음 설정

## 변경 분류

- 의도한 계약: 사용 한도가 초기화되면 그 프로필의 효과음과 알림 툴팁을 한 번
  표시한다(v0.33.0, v0.33.16, v0.33.17). 효과음과 툴팁은 둘 다 사용자가 다시
  입력할 때까지 보류한다. 효과음 on/off는 프로필마다 설정 파일의
  `limit_reset_sound_enabled`에만 있다.
- 현재 동작: 계약과 같다. 자리를 비운 동안 초기화되면 돌아와 입력하는 순간
  효과음과 툴팁이 함께 나온다. 효과음을 끄려면 프로필마다 JSON 파일을 고쳐야
  하고, Claude 모니터는 설정 변경 함수로 이 값을 받지 않는다.
- 차이: 사용자가 자리를 비운 동안에도 효과음이 울리는 알림 정책과, 효과음을
  GUI에서 켜고 끄는 설정을 요청했다.
- 판정: 기존 계약의 결함 복구가 아니라 새 알림 정책과 새 사용자 설정이므로
  `release/v0.34.0`에서 제공한다.

## 동작 계약

AI 사용량 설정 탭의 옵션 줄 아래에 두 설정을 둔다. 둘 다 모든 프로필에 공통이고
기본값은 켜짐이다.

| 초기화 효과음 | 자리 비움 중에도 재생 | 초기화를 감지했을 때 | 사용자가 다시 입력할 때 |
|---|---|---|---|
| 켜짐 | 켜짐 | 효과음 재생 | 툴팁 표시(소리 없음) |
| 켜짐 | 꺼짐 | 대기 | 효과음과 툴팁 표시(v0.33.x 동작) |
| 꺼짐 | 무관 | 대기 | 툴팁만 표시 |

- 툴팁은 설정과 관계없이 지금처럼 다음 입력까지 보류한다. 자동으로 사라지는
  툴팁을 자리에 없을 때 띄우면 놓치기 때문이다.
- 초기화 하나는 효과음을 한 번만 낸다. 감지 때 울린 초기화는 복귀 때 다시 울리지
  않는다. 자리를 비운 동안 다른 한도나 다른 프로필이 초기화되면 그때마다 울린다.
- 감지 때 울리지 않은 초기화가 보류 중에 하나라도 있으면 복귀 때 한 번 울린다.
  예: 보류 중에 "자리 비움 중에도 재생"을 끈 뒤 새 초기화가 들어온 경우, 감지 때
  재생에 실패한 경우(오디오 장치 없음 등).
- "초기화 효과음"을 끄면 "자리 비움 중에도 재생"은 비활성으로 표시한다. 값은
  유지되어 효과음을 다시 켜면 이전 선택이 돌아온다.
- Windows가 실제 절전 상태면 앱도 멈춰 있어 소리를 낼 수 없다. PC가 깨어난 뒤
  다음 조회에서 초기화를 감지하는 즉시 설정에 따라 울린다.

## 설정 저장과 전달

- 두 값은 프로필 관리자의 `ai_usage_settings.json`에 `limit_reset_sound_enabled`,
  `limit_reset_sound_while_away`로 저장한다. 설정 파일 버전(4)은 바꾸지 않는다.
- 프로필 모니터(Codex, Claude)는 생성될 때 관리자의 정책 함수를 받고, 알림을
  낼 때마다 그 값을 읽는다. 설정을 바꾸면 모니터를 다시 만들거나 값을 밀어 넣지
  않아도 모든 프로필에 바로 적용된다. v0.33.17의 알림 이름 함수와 같은 방식이다.
- 관리자 파일에 `limit_reset_sound_enabled`가 없으면(v0.33.x에서 올린 경우), 각
  프로필 설정 파일의 기존 값을 본다. 값이 있는 프로필이 모두 꺼져 있을 때만 끔으로
  시작하고, 나머지는 켬으로 시작한다. 그 뒤 처음 저장할 때 관리자 파일에 기록되어
  이후에는 프로필 파일 값을 보지 않는다.
- 관리자 없이 프로필 모니터만 쓸 때는 모니터 자신의 설정 파일 값을 쓴다. 두
  모니터 모두 두 키를 설정 스냅샷, `update_settings`, 설정 파일에서 다룬다.
- Cursor는 초기화 알림이 없어 이번 범위에 포함하지 않는다.

## 검증 범위

- 공용 알림 모듈: 감지 때 재생하고 툴팁은 입력 뒤 소리 없이 표시, 자리 비움 중
  두 번째 초기화의 별도 재생, 설정 꺼짐의 복귀 재생, 효과음 꺼짐의 무음, 보류 중
  설정 변경 뒤 새 초기화의 복귀 재생, 감지 때 재생 실패의 복귀 재시도, 입력 확인이
  안 되거나 창이 없을 때의 즉시 처리, 정책 함수 오류 시 무음과 툴팁 유지.
- Codex 모니터: 감지 때 재생과 입력 뒤 무음 툴팁, 설정 꺼짐의 복귀 재생, 보류 중
  설정 변경 뒤 새 초기화의 복귀 재생, 감지 때 재생 실패의 복귀 재시도, 관리자
  정책이 모니터 자신의 값보다 우선하고 오류 시 자신의 값으로 돌아가는 것,
  설정 파일 저장.
- Claude 모니터: 두 키의 스냅샷·`update_settings`·설정 파일 저장, 관리자 정책
  우선과 오류 시 복귀.
- 프로필 관리자: 저장·재시작 유지, 기존 프로필과 새 프로필 모두 같은 정책을
  읽는 것, 자식 설정으로 값을 밀어 넣지 않는 것, 저장 실패 시 값 불변, 저장된
  값의 우선. 프로필 파일에서의 기본값 이전은 관리자 파일이 없는 첫 실행과, 값이
  없는 v4 관리자 파일(v0.33.x에서 올린 경우)에서 첫 저장 전까지 이전 값을 쓰다가
  첫 저장 때 기록하는 경로를 모두 확인한다.
- 설정 화면: 두 체크박스와 비활성 연동, 자동 저장, 불러오기, 화면에 없을 때
  키를 보내지 않는 것.
- 새 시험은 수정 전 코드(`f1cca0e`)에서 실패한다.
- 합성 데이터 native Tk 확인: 기본, 효과음 꺼짐, 클릭으로 끈 뒤 자동 저장, 좁은
  창(520px), 150% 배율에서 네 체크박스가 창 안에 보이고 하위 옵션 상태가 맞다.
- 전체 unit/E2E는 실행하지 않았다. 변경한 알림·설정 경로와 관계없는 기능으로
  확대하지 않았다. 실제 효과음을 스피커로 듣는 확인은 하지 않았다.
