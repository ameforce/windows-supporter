# 날짜별 Wrike 실제 기록 상세

`Ctrl+Alt+W` 근무시간 패널에서 요일 행을 누르면 그 날짜의 실제 Wrike 타임로그를 확인할 수 있다. 각 기록은 티켓 이름, 기록 시간, 코멘트로 표시하며, 선택한 날짜의 합계를 함께 표시한다. 기록이 없을 때와 조회 중 또는 조회할 수 없을 때는 서로 다른 안내를 표시한다.

기록이 길면 상세 영역을 스크롤해서 확인할 수 있다. 같은 날짜가 동기화되어도 읽던 위치는 유지하고, 다른 날짜를 선택하면 새 날짜의 처음부터 표시한다.

타임로그 본문과 티켓 제목은 현재 앱 세션의 메모리에만 보관한다. `%APPDATA%\windows-supporter\wrike_timelog_cache.json`에는 기존처럼 날짜별 분 단위 합계만 저장한다.

티켓 제목은 같은 `taskId`를 한 번만 묶어 백그라운드에서 조회한다. 삭제되었거나 접근할 수 없는 티켓, 일시적으로 제목을 조회하지 못한 티켓은 화면에서 구분한다. 새로고침 실패 때에는 마지막으로 정상 조회한 상세를 유지하며, 주가 바뀌거나 계정이 바뀌거나 오래된 조회 결과가 도착하면 그 상세를 사용하지 않는다.

패널을 여는 기본 경로와 자동 새로고침은 현재 사용 중인 앱의 키보드 포커스를 가져오지 않는다. 패널 안에서 사용자가 시간 입력을 선택한 경우에만 해당 입력칸으로 포커스를 이동한다.
