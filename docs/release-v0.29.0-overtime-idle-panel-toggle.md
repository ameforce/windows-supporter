# v0.29.0 근무시간 패널 초과근무 자동 일시정지 토글 계약

## 변경 분류

- 의도한 계약: 무입력 자동 일시정지(v0.28.0)의 on/off는 설정 창에서만
  제어한다.
- 현재 동작: Ctrl+Alt+W 근무시간 패널은 자동 일시정지 상태를 표시만 하고
  토글할 수 없다.
- 차이: 초과근무가 진행 중일 때 패널에서 직접 자동 일시정지 기능을 켜고 끄는
  경로가 없었다.
- 판정: 기존 의도에 없던 사용자 기능이므로 `release/v0.29.0`에서 제공한다.

## 동작 계약

- 초과근무 상태 카드의 동작 행에 "자동 일시정지 끄기/켜기" 버튼이 추가된다.
  버튼 라벨은 현재 `overtime_idle_pause_enabled` 설정값을 반영한다.
- 클릭하면 `update_settings({"overtime_idle_pause_enabled": <반전>})`를 통해
  설정을 반전·영속화한다. 저장 실패 시 설정값은 바뀌지 않고 패널 오류만
  표시한다. 저장 성공 시 이미 열려 있는 설정 탭 뷰는
  `refresh_overtime_idle_settings()`로 자동 일시정지 입력란만 다시 읽어
  stale 입력값이 새 설정을 덮어쓰지 않게 한다(다른 필드의 진행 중 입력은
  유지한다).
- `update_settings`의 flex 재스케줄 경로는 기존 `after` 콜백을 먼저 취소해
  반복 설정 저장이 flex 폴링 체인을 중복으로 만들지 않는다.
- 토글은 기능의 on/off만 바꾼다. 진행 중인 타이머의 수동/자동 일시정지 상태
  자체를 건드리지 않으며, 이미 자동 일시정지된 타이머는 v0.28.0 계약대로
  다음 입력에서 자동 재개된다.
- `WorktimeOvertimeState.idle_autopause_enabled`는 bool 필수이고 패널은
  `overtime_idle_autopause` 콜백을 제공받는다. 콜백 미제공 시 버튼은
  no-op이다.

## 검증 범위

- 패널 버튼 라벨이 설정값을 반영하고 클릭이 콜백으로 전달되는 것,
  `idle_autopause_enabled`의 bool 검증을 단위 테스트로 검증한다.
- Wrike 핸들러가 설정을 반전·영속화하고 실패 시 flag를 유지하는 것을 단위
  테스트로 검증한다.
- 설정 창의 기존 토글과 동일 설정키를 공유하므로 양쪽이 같은 값을 읽는다.
