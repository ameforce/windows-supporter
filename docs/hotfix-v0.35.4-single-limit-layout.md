# 단일 사용량 프로필의 공통 열 배치

의도한 계약은 프로필마다 사용량이 하나라면 같은 시작 위치에 표시하고 크레딧은 별도 열로 유지하는 것이다. 현재 구현은 모든 프로필의 한도 종류를 합쳐 열을 만들므로 주간 한도만 있는 행과 월간 한도만 있는 행 사이에 빈 열이 생긴다. 기존 표시의 여백을 줄이는 보완으로 `hotfix/v0.35.4`로 분류한다.

모든 표시 행에 사용량이 최대 하나이고 그 종류가 5시간, 주간, 월간 한도이면 사용량 열을 공유한다. 하나라도 여러 사용량을 표시하거나 다른 종류의 항목을 포함하면 기존 항목별 공통 열 정렬을 유지한다. 원래 항목의 이름, 값, 기간, 색상, 툴팁은 그대로 유지하며 배치에 사용하는 열만 합친다. 공유 폭은 가장 긴 기간 표시와 크레딧 금액을 수용한다.

직접 영향 범위는 `codex_usage_taskbar_overlay.py`의 공통 열 계산과 이를 사용하는 폭 계산, 그리기, 툴팁 위치다. 검증은 단일 사용량 회귀 시험, 기존 오버레이와 크레딧 폭 시험, 변경된 두 행의 실제 Tk 렌더링에 한정한다. 전체 앱 E2E와 전체 테스트 모음은 관련 없는 범위여서 실행하지 않는다.

## 검증 결과

- 수정 전 새 회귀 시험에서 빈 열과 서로 다른 퍼센트 폭 문제를 재현했다.
- 단일 사용량 배치, 기존 오버레이, 크레딧 폭에 대한 322개 시험을 통과했다.
- 실제 Tk 글꼴로 권장 폭, 480px, 720px의 두 행을 그려 사용량 시작점과 크레딧 정렬, 금액 잘림 여부를 확인했다.
- 독립 검토에서 중요한 결함이 없었고 추가 변경의 직접 시험 9개도 통과했다.
- Pro 검토는 세션 확인 단계의 `CHALLENGE_REQUIRED`로 자료 전송 전에 중단됐다. 완료된 검토로 집계하지 않는다.
