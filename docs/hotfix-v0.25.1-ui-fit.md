# v0.25.1 Quick Panel UI fit hotfix

## 분류 판정

- 의도한 계약: Quick Panel의 주요 버튼은 작은 작업 영역에서도 온전한 높이로 표시되어야 하며, 선택 날짜 타임로그의 티켓명은 한 줄만 차지하고 폭을 넘으면 `...`으로 축약되어야 한다.
- 현재 동작: 상세 Text 영역이 액션 행을 아래로 밀어 작은 화면에서 버튼의 일부만 노출하고, 긴 티켓명이 word wrap으로 두 줄 이상 표시된다.
- 차이: 고정된 상세 영역과 일반 상단 pack 순서가 하단 액션 영역을 보호하지 못하며, 티켓명 표시용 폭 제한이 없다.
- 판정: 새 capability가 아닌 기존 표시 계약의 회귀·가독성 보정이므로 `hotfix/v0.25.1`로 분류한다.

## 변경 범위

- 액션 버튼과 닫힘 카운트다운을 하단 footer에 고정해 상세 영역이 버튼을 밀어내지 않도록 한다.
- 버튼 높이를 명시해 Tk 자연 크기 계산에서 버튼이 찌그러지지 않게 한다.
- 티켓명을 공백·개행 기준으로 한 줄화하고, 실제 상세 viewport 폭에 맞춰 `...`을 붙여 축약한다. viewport 폭이 확정되면 Configure 이벤트로 다시 맞춘다.
- 첨부 PNG는 현상 확인을 위한 시각 자료로만 사용했으며, 문서의 별도 실행 지시로 취급하지 않는다.

## 검증 범위

- 타임로그 상세·버튼 footer 회귀 unit test
- 작은 Native Tk viewport에서 주요 액션 버튼 매핑·높이·하단 경계 확인
- 기존 Wrike break/edit 회귀와 native panel QA
